# rev008 변경 이력

Requiem Legion: Coarse Edition에서 **위태로운 갈망(That Perilous Yearning)**을 켜면, 선택받은 자에게 같은 지속 효과가 중복되던 문제와 고른 카드의 효과가 전투에서 빠지던 문제를 바로잡는다. 코덱스에게 두 강화를 주면 한 번의 사이오닉 폭탄으로 두 효과를 모두 적용할 수 있다.

| 대상 | 플레이 중 달라지는 점 |
|---|---|
| 어쌔신·헌터·워록 | 보석·헌신으로 받은 같은 영구 지속 효과는 유닛을 초기화할 때 한 번만 남는다. 권능·변화의 헌신은 공격자가 보는 표적의 엄폐에 따라 명중과 치명타를 보정한다. |
| 고급·정예 어드밴트 기사 | 사이오닉 활로 쏠 대상이 없거나 활이 재사용 대기 중이어도 자신에게 ‘헌신의 방패’를 쓸 수 있다. |
| 사제 | ‘시간 이동’은 표적을 **사제가 턴을 시작한 칸**으로 옮긴다. 도착할 수 있는 칸인지 확인하고 사제가 마지막으로 받은 피해를 표적에게 한 번 적용한다. 사제의 피해 기록이 없으면 이동만 한다. |
| 스펙터·섹토이드 | 스펙터는 ‘유령 신호’만 골라도 기계 유닛을 탈취할 수 있다. 섹토이드는 ‘실업자들의 전성시대’를 골랐을 때 이동을 마치면 범위 안의 전리품을 회수한다. |
| 코덱스·스펙터·버서커 | ‘고난의 코덱스’는 폭발물을 봉쇄하고 ‘성배의 저주’는 능력 충전을 줄인다. 스펙터는 ‘수수께끼 공학’으로 은신 시 회복하고, 버서커는 ‘척추 파괴자’로 주 표적과 주변에 추가 피해를 준다. |
| 능력치 대결과 병종 강화 | 섹토이드의 ‘기억술’, 스턴 랜서의 기절, 버서커·뮤톤의 상해 강화는 실제 공격 능력치 대결에 +40을 준다. 어드밴트 병사의 ‘스마트 조준경’은 일반 명중 +20, 뮤톤의 ‘잔혹한 근력’은 찰과상 방지를 적용한다. |
| 폭발 반경과 이동 | 로켓·수류탄이 각자의 반경 강화 카드를 읽는다. 섹토이드·바이퍼는 ‘미끄러운 추적자들’의 치명타 특성을, 페이스리스·버서커는 ‘적응형 근육 조직’의 이동 전용 행동력 하나를 받는다. |

**선택 순서.** 같은 대상에 영향을 주는 두 선택지 3,178쌍을 양방향으로 적용해 능력·장비·수량이 일치했다. 세 개 이상인 대표 묶음 51개도 같은 결과였다. 캠페인에서는 카드 등장 월에 따라 한쪽 순서만 가능하다. 선택받은 자의 보석은 각자 576개 조합의 능력과 공격·피격 예측을 확인했고, 실제 적 턴은 30개 편성에서 진행했다. [조합별 결과와 미확인 항목](../reports/ModReport_CoarseEnemyAIAndEncounters_rev008.md)
