## 공개 자료

rev004와 rev005를 처음 추가할 때 각 버전의 모드 설명자·설정·컴파일 패키지·소스와 검증 기록을 함께 보관했다. 같은 모드 ID를 사용하므로 게임에서는 한 버전만 활성화한다. [기존 설치 안내](../README.md) · [버전별 변경 이력과 패키지 해시](../CHANGELOG.md)

rev004 보고서의 카드 화면 56장과 모음 4장은 검증 당시 PNG 원본과 바이트 단위로 대조했다. rev004 실행 12개와 rev005 작업의 실행 16개에서 시험 표식, 빌드 결과 및 해당 헌터 회전 경고를 발췌했다. rev005 작업의 16개 기록에는 수정 전 대조, 탐색 실행과 SDK 빌드도 들어 있다. 전술 시험의 완료 횟수는 14회다. 같은 실행에서 기록한 행은 시각과 값을 보존했고, 큰 임무 표는 나누어 보관했다.

## 배포 검증과 재현

| 검증 방식 | 당시 재현 조건·절차 | 기대 결과 | 당시 관찰 | 상태 |
|---|---|---|---|---|
| 버전별 파일 비교 | 두 폴더에서 상대 경로별로 SHA-256 계산 | 로컬 배포본과 공개본의 경로·파일 내용 일치 | 5개 버전 149개 모드 파일의 상대 경로와 SHA-256 일치. 각 버전에 모드 설명자와 컴파일 패키지 포함 | 통과 |
| 이전 버전 보존 | rev001~003을 기존 배포 사본과 비교 | 기존 배포본과 공개 보고서 보존 | rev001~003 모드 파일 61개와 기존 공개 보고서 3개의 내용 일치 | 통과 |
| 문서 탐색 | 당시 저장소 루트에서 보고서 링크와 문서 내 위치 확인 | 저장소 안에서 설치본·소스·표·화면·로그 열기 | 다섯 버전의 경로, 보고서의 내부 링크와 문서 내 위치 확인 | 통과 |
| Windows Git에 추가 | 별도 Windows 작업 폴더에서 줄바꿈 자동 변환을 켜고 추가 | 자동 줄바꿈 변환을 켜도 파일 내용 보존 | 독립 작업 폴더에서 258개 파일을 Git에 추가한 뒤 각 객체가 가리키는 내용과 배포 파일을 대조 | 통과 |
| 압축 확인 | 당시 생성한 ZIP을 열어 폴더와 항목별 비교 | 폴더에서 보이는 모든 배포 파일이 ZIP 루트에서 같은 경로로 열림 | ZIP을 다시 열어 전체 파일 목록, CRC와 파일별 SHA-256 일치 확인 | 통과 |

이 검사를 반복하려면 당시 ZIP을 빈 폴더에 풀고 버전별 파일 개수와 컴파일 패키지 해시를 대조한다. 보고서 본문은 이후 개정됐으므로, 당시 문서 3개의 바이트 일치와 Git 객체 258개는 과거 배포본에만 해당한다. 게임 내 결과는 각 버전의 전술·캠페인 보고서에 기록되어 있다.
